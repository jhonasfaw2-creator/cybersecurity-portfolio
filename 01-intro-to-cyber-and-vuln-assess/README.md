# Module 1: Introduction to Cybersecurity & Vulnerability Assessment

## Key Concepts & Vulnerability Notes
- **Vulnerability Assessment & Reconnaissance:** Identifying open ports, misconfigured services, and outdated software using tools like **Nmap** before attackers can exploit them.
- **Data Security & CIA Triad:** Enforcing Confidentiality, Integrity, and Availability through encryption, access controls, and secure backup policies.
- **Social Engineering Defense:** Mitigating phishing, pretexting, and credential harvesting through user awareness, MFA, and email filtering.
- **Risk Mitigation:** Prioritizing remediation based on exploitability and business impact.
