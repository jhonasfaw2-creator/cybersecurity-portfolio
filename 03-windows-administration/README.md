# Module 3: Windows Server Administration

## Topics Covered
- **Active Directory Domain Services (ADDS):** Domain controller setup, Organizational Units (OUs), Group Policy Objects (GPOs), and user management.
- **Network & Deployment Services:** Automated IP allocation via **DHCP** and OS image deployment via **Windows Deployment Services (WDS)**.
- **Security & Storage:** Implementing the **Principle of Least Privilege (PoLP)**, NTFS permissions, and RAID/disk storage management.
