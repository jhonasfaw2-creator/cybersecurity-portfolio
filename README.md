# Cybersecurity Portfolio

Hands-on labs, network topologies, and system administration configurations completed during my **Advanced Cybersecurity Program (IBT College of Canada)** and **ALX Cybersecurity Training**.

## Repository Structure
- **`01-intro-to-cyber-and-vuln-assess/`** — Vulnerability assessments, social engineering defenses, and data security write-ups.
- **`02-computer-networking-cisco/`** — Cisco Packet Tracer (`.pkt`) topologies covering Multi-Area OSPF, EIGRP, VLANs, Trunking, and Router-on-a-Stick.
- **`03-windows-administration/`** — Windows Server administration labs: Active Directory Domain Services (ADDS), DHCP, Windows Deployment Services (WDS), storage management, and Principle of Least Privilege.
- **`04-linux-admin-and-servers/`** — Linux server administration, containers, web servers, databases, and system hardening.
- **`05-enterprise-network-security/`** — Firewall policy configuration (pfSense), network reconnaissance (Nmap), and perimeter defense.
- **`06-vuln-assessment-and-infrastructure/`** — Infrastructure operation, vulnerability management, and system hardening.
- **`07-digital-forensics-and-incident-response/`** — Incident investigation, evidence acquisition, and digital forensics.
- **`08-ethical-hacking-and-pen-testing/`** — Ethical hacking, penetration testing methodologies, and exploit analysis.
